# Bolt

一个 AI 原生产品的公开构建日志。

这里记录一个 AI 创业项目从 0 到 1 的**公开面**：工作方法、构建节奏、阶段性进展。商业与产品细节不在此仓库。

## 公开文档

| 文件 | 内容 |
|---|---|
| [AGENT.md](AGENT.md) | 工作区协作说明（人与 AI agent 的工作约定） |
| [TODO.md](TODO.md) | 公开路线图与当前进度 |
| [memo.md](memo.md) | 备忘思考：方法论与学习记录（脱敏） |

## 这个仓库怎么用

- 想了解我们在做什么：读 [memo.md](memo.md) 和 [TODO.md](TODO.md)。
- 想参与协作（人类或 agent）：先读 [AGENT.md](AGENT.md) 的约定。
- 所有涉及商业计划、产品需求、品牌策略的内容都保存在本地，不进入本仓库。

## 原则

1. 公开构建：过程可见，进展如实更新。
2. 边界清晰：公开方法与节奏，保留商业细节。
3. 证据优先：进展以可验证的产出为准，不写形容词。

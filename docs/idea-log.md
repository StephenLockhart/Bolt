## 001 · 2026-10-21 · 初始想法（原始输入，尽量原样保留）

1. 想做一个 AI 创业企划，目前还是很雏形的阶段，先把 PRD 写好，工作慢慢来，现在没想好怎么做，先把思路和创意记录下来。
2. 产品形态（未定）：Agent 软件 / 插件 / 平台 / MCP，放在 **codex 或者 dsh** 里（"dsh" 为用户原文，具体指代什么宿主环境待确认）。
3. 核心创意：**快慢机思维**。
   - 现在的 AI 思考方式太单一了，应该把长短思考分开。
   - 现在的应用基本上都是短思考。
   - **长思考**：应该是持续好几天的，然后任务断断续续的。
   - **短思考**：表面思考，可以一直和人交流、对需求。
4. 依据："就像 A 社（Anthropic）说的，人的注意力是有限的"；另外建议看看 OpenAI 的相关研究。
5. 协作方式（原始输入）："有必要的文件你可以上传的 github 或者定期保存或者做分支都行"；"我把我的思路都断断续续给你，其实这就是一个短思考对话形式，然后你在后台一直做长对话思考"。

### 我对原始想法的即时解读（标注，非原话）

- "快慢机" 借自枪械的快慢机（射速选择器）：同一个执行体，切换"单发/连发"两种节奏。产品里对应同一个 AI 的两种思考节奏档位。
- 隐含的核心主张：**人的注意力是稀缺资源，AI 的"思考时长"不应该被人类在线时长绑定**。短思考伺候人，长思考伺候任务。
- "断断续续"是长思考的关键词：不是一次性长跑，而是跨天、可中断、可恢复的多段推进。
- 创始人正在用"和我聊天"直接演示短思考，用"让我后台写 PRD"直接演示长思考——产品价值主张已经被亲身验证了一半。

### 外部概念依据（2026-10-21 检索，供 PRD 引用）

- Anthropic《Effective context engineering for AI agents》（2025-09-29）：LLM 有"注意力预算"（attention budget），上下文是边际收益递减的有限资源；人也一样——这就是"人的注意力是有限的"的技术类比。文中给出长时程任务的手法：compaction（压缩）、note-taking（笔记沉淀）、sub-agents as budget isolation（用子代理隔离预算）。
  - <https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents>
- OpenAI《Introducing Workspace Agents in ChatGPT》（2026-04-22）：云端 Agent 在用户离线时持续工作，处理"复杂的任务和长期运行的工作流"，在必要时请求人工审批。行业正在从"单会话短思考"走向"后台长跑"，但缺的正是**快慢两档在同一工作面上的切换与回流机制**——这是本产品的差异点机会。
  - <https://openai.com/zh-Hans-CN/index/introducing-workspace-agents-in-chatgpt/>
- 认知科学源头：Kahneman《思考，快与慢》（Thinking, Fast and Slow）的双系统理论（System 1 快思考 / System 2 慢思考），"快慢机"一词的命名依据。

## 1 命名原则（复制 minimax 的结构）

minimax = **mini + max**：两个反义语素熔成一个词，短、常见词、口语顺、读者自己完成"矛盾统一"的解码。照此结构，我们的命名约束为：

1. 两个语素必须是一对**反义/对立**概念，直接映射快挡与慢挡；
2. 每个语素是常见英文单词（或单音节），合起来一个词、无连字符优先；
3. 读音响亮、拼写可猜（听到能写出来）；
4. 隐喻要能被 Logo（齿轮/传动/CVT）接住；
5. 避开已占用的科技品牌词；商标与域名需正式检索。

## 3 推荐

- **主推 SnapSimmer**：反差结构最完整、双 S 押韵最好记、"快炒慢炖"的故事和"快挡陪人说话 / 慢挡后台慢炖"严丝合缝，且 Logo 的齿轮/传动隐喻不冲突（厨房里也有火候与节奏）。
- **机械系备选 BurstBatch**：如果希望品牌气质与 Logo 的机械/弹道隐喻完全统一（连发、单发、齿轮、传动），选它，牺牲一点生活化的亲和力。
- 中文语境对外表达建议保留"**快慢机**"作为产品昵称/中文名，与英文名并行（如 SnapSimmer · 快慢机）。

## 4 Logo 设计简报

### 4.1 隐喻映射（这是 Logo 的灵魂，任何视觉改动不得破坏）

| 元素 | 对应产品概念 | 视觉要求 |
|---|---|---|
| 大齿轮 | 慢挡 / 长思考：转得慢、扭矩大、走得远 | 大而稳，齿形厚 |
| 小齿轮 | 快挡 / 短思考：转得快、响应快 | 小而灵，位置略高/前置 |
| 传动件（轴或皮带） | 交接协议：简报、进展摘要 | **唯一彩色元素**，是视觉焦点 |
| 无级变速（CVT） | 快慢配比随任务变化，不是固定齿比 | 皮带方案用可变径暗示；不用固定齿比的刚性表达 |
| 整体 | 巧妙耦合 > 零件之和 | 构图紧凑，两轮一耦合，一读即懂 |

### 4.2 三方案

- **方案 A · 传动轴版**：大小齿轮共轴刚性连接，结构最稳、最"机械"。权衡：刚性轴=固定速比，与"无级"理念内在冲突，更适合表达"可靠"而非"自适应"。
- **方案 B · 皮带无级变速版（推荐）**：大小两轮 + 一条皮带（或锥轮可变径暗示），直接对应 CVT 隐喻——速比随任务无级变化。权衡：细节比 A 多，缩到 favicon 尺寸需出简化版（即方案 C）。
- **方案 C · 极简速比版**：去掉齿形，单线两圆 + 皮带，为小尺寸（favicon / 16px）准备的简化态。权衡：机械感减弱，单独用偏"通用圆环"。

### 4.3 设计规则

1. 大小轮直径比约 **2:1**；若画齿形，大轮齿数 = 2 × 小轮齿数（啮合关系正确，内行看得顺眼）。
2. 传动件是唯一允许上色的元素（颜色 = 耦合 = 产品的价值所在）；齿轮本体走中性墨色/线条。
3. 必须有单色版与反白版；不得依赖渐变、立体齿、写实材质。
4. 三个尺寸锚点验收：48px（App 图标）、24px（网页头）、16px（favicon）；16px 下允许退化为方案 C。
5. 文字标（wordmark）与图形标（mark）可分可合：横排组合用于官网头部，mark 单独用于产品内。

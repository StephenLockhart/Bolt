## 1 命名原则（复制 minimax 的结构）

minimax = **mini + max**：两个反义语素熔成一个词，短、常见词、口语顺、读者自己完成"矛盾统一"的解码。照此结构，我们的命名约束为：

1. 两个语素必须是一对**反义/对立**概念，直接映射快挡与慢挡；
2. 每个语素是常见英文单词（或单音节），合起来一个词、无连字符优先；
3. 读音响亮、拼写可猜（听到能写出来）；
4. 隐喻要能被 Logo（齿轮/传动/CVT）接住；
5. 避开已占用的科技品牌词；商标与域名需正式检索。

## 3 推荐

- **主推 SnapSimmer**：反差结构最完整、双 S 押韵最好记、"快炒慢炖"的故事和"快挡陪人说话 / 慢挡后台慢炖"严丝合缝，且 Logo 的齿轮/传动隐喻不冲突（厨房里也有火候与节奏）。
- **机械系备选 BurstBatch**：如果希望品牌气质与 Logo 的机械/弹道隐喻完全统一（连发、单发、齿轮、传动），选它，牺牲一点生活化的亲和力。
- 中文语境对外表达建议保留"**快慢机**"作为产品昵称/中文名，与英文名并行（如 SnapSimmer · 快慢机）。

## 4 Logo 设计简报

### 4.1 隐喻映射（这是 Logo 的灵魂，任何视觉改动不得破坏）

| 元素 | 对应产品概念 | 视觉要求 |
|---|---|---|
| 大齿轮 | 慢挡 / 长思考：转得慢、扭矩大、走得远 | 大而稳，齿形厚 |
| 小齿轮 | 快挡 / 短思考：转得快、响应快 | 小而灵，位置略高/前置 |
| 传动件（轴或皮带） | 交接协议：简报、进展摘要 | **唯一彩色元素**，是视觉焦点 |
| 无级变速（CVT） | 快慢配比随任务变化，不是固定齿比 | 皮带方案用可变径暗示；不用固定齿比的刚性表达 |
| 整体 | 巧妙耦合 > 零件之和 | 构图紧凑，两轮一耦合，一读即懂 |

### 4.2 方向修正 v2（2026-10-21 反馈后）

**原则：抽象机构本质，不画零件。** 对标 Steam 的 logo——它是一台"蒸汽机"的抽象（活塞连杆的运动本质），不是零件装配图。据此删掉齿形、轮毂、锥轮、皮带缝线等一切零件细节，只保留三个关键信息：

1. **两个不等大的轮**——快慢反差（大轮=慢挡，小轮=快挡）；
2. **传动件**——耦合（皮带环 / 轴），是唯一可上第二色的元素；
3. **循环 / 转动感**——持续与联动。

复合方向为 **A×B**：A 的轮与轴（机械、可靠）× B 的皮带环（柔性、无级）。三个抽象稿（v2）：

- **V1 · 双轮皮带环（推荐）**：胶囊形皮带环 + 两个不等大实心轮（轮心留轴点，A 的"轴"由此保留）。信息完整、缩放最强、单色成立。
- **V2 · 双环双切线**：皮带进一步抽象为上下两条切线，轮改为空心环。最极简，但 16px 下环口易糊。
- **V3 · 斜置传动**：大小实心轮斜置 + 一根传动轴，构图带速度感。最"机械"，但对齐与缩放略费劲。

### 4.3 设计规则（v2）

1. 元素预算 ≤ 4：两轮 + 传动件 +（可选）轴点；禁止齿形、渐变、立体、写实材质。
2. 单色可用、反白可用；第二色只允许出现在传动件（= 耦合 = 产品灵魂）。
3. 线宽统一、端点圆角；轮廓比例在 200 单位视图内线宽约 6~8。
4. 尺寸锚点验收：48 / 24 / 16px；16px 下 V1 直接可用，V2 可能需并掉环口。
5. 文字标与图形标可分可合；横排组合用于官网头部，mark 单独用于产品内。

### 4.4 视觉简报 v3（设计系统，参照专业视觉设计方法论）

- **三个形容词**：精密、克制、联动。
- **一个设计张力**：机械严谨 × 速度动感（对角构图给动感，几何正形给严谨）。
- **配色逻辑**：墨色为体（轮），品牌色只给传动件（皮带/轴点）——颜色 = 耦合 = 价值所在；灰度下单色仍成立。
- **字体逻辑**：无衬线、字重只用两档（Medium/Regular）；若配文字标，大写 + 字距放宽。
- **空间节奏**：图形在方形安全区内光学居中（大轮视觉重，成对轮心整体右移约 3% 平衡）；线宽 8/240 视图单位，端点全圆角。
- **必做检验**（每稿过一遍）：① 灰度化后层级不变；② 16px 缩略仍可辨；③ 反白版不糊；④ 视觉重心不偏。
- **构成辅助线**：pitch 圆与轴线用发丝级虚线呈现于设计稿（交付时移除），体现"机构几何"身份。

### 4.5 v3 精修记录（2026-10-21）

- V1（双轮皮带环）：轮对右移做光学平衡；皮带环与轮的间隙统一；轴点比例 2:1。
- V3（斜置传动）：轴线定为精确 30° 对角；轴从轮缘平滑穿出；大小轮沿轴线排布。
- 两稿均附验证条：48/24/16 尺寸阶梯、灰度版、反白版。
- V2（双环双切线）暂缓：语义弱、小尺寸易糊。

# 模板 · 一页纸（One-Pager）

> 用途：投资助方 / 天使 / 设计伙伴。600 字以内，一屏能读完。

## 结构

**标题**（项目名 + 一句主张）

**一句话**：谁的问题 + 我们怎么解 + 结果

**问题**：3 句以内，场景化

**方案**：3-5 个要点，每条一行

**为什么现在**：2-3 条外部变化

**为什么是我们**：只写可核查的（已有产出、原型、数据）；没有的标 [待填]

**钱用来做什么**：分项 + 比例 + 总额

**里程碑**：3 / 6 / 12 个月，各一条可验证指标

**联系方式**：[姓名] · [邮箱] · [链接]

## 检查
- [ ] 全文 ≤ 700 字
- [ ] 没有未标注来源的数字
- [ ] 没有编造的履历
- [ ] 结尾注明"不构成募资承诺"

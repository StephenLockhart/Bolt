# 工具与插件清单

> 我们手上有什么工具、什么时候用哪个。避免每次都从零想"这个该用什么做"。

## 一、内容生产

| 工具 | 能力 | 我们什么时候用 |
|---|---|---|
| **Office 文档处理**（docx/pptx/xlsx/pdf） | 生成与编辑 Word / PPT / Excel / PDF | BP 导出 PDF、财务模型 xlsx、设计伙伴报价单 |
| **HTML 报告与演示**（html-report / html-deck） | 自包含 HTML 报告与幻灯片 | 官网、投资人一页纸网页版、数据仪表 |
| **高质量 PPT**（jingmei-ppt） | 视觉设计方法 + PptxGenJS | 路演 PPT（需要"好看"时） |
| **PRD 写作** | 结构化 PRD + 原型 | 把 04-PRODUCT 扩成可开发规格时 |

## 二、视觉素材

| 工具 | 能力 | 我们什么时候用 |
|---|---|---|
| **Seedream**（生图） | 文生图、插画、视觉资产 | 官网配图、文章头图、演示封面 |
| **Seedance**（生视频） | 文生视频、图生视频、视频延长 | 演示视频的片头/概念动画（真实操作仍需录屏） |
| **dynamic-ui** | 内联 SVG/HTML 可视化 | 快速对比方案（如标志四个方向、动效对比） |

## 三、研究与验证

| 工具 | 能力 | 我们什么时候用 |
|---|---|---|
| **Deep Research** | 多源检索 + 交叉验证 + 研究报告 | 竞品分析、市场口径、资助方核实 |
| **Context7** | 拉取版本化官方文档 | 接入第三方 SDK/API 时查准用法 |
| **AE 互联工具集**（agent-earth） | 1400+ API：行情、电商、社媒、地图、学术 | 需要外部结构化数据时 |
| **TRAE-browseruse** | 真实浏览器操作与截图 | 验证网页实际渲染、录演示、检查移动端 |

## 四、工程与协作

| 工具 | 能力 | 我们什么时候用 |
|---|---|---|
| **GitHub** | 仓库、分支、PR、issue、release | 公开主页维护、开源交接协议 spec |
| **skill-creator** | 创建可复用 skill | 把重复流程固化成 skill |
| **schedule** | 定时任务 | 每周自动快照、定期检查官网窗口 |
| **feedback** | 提交问题反馈 | 工具本身出问题时 |

## 五、我们自己的脚本（library/scripts/）

| 脚本 | 作用 | 何时跑 |
|---|---|---|
| `snapshot.sh` | 打包 docs + library 到 `.local-backups`，保留 20 份 | **每次改动前** |
| `check_html.py` | HTML 标签闭合校验 | 改完 HTML 后 |

## 六、纪律

- 生成类工具（生图/生视频）只用在不影响事实的地方；**产品界面截图必须真实录屏**，不用生成图代替
- 研究类结论必须带链接；插件给的数字同样要标来源
- 新增工具时在本页追加一行，写清"什么时候用"，否则等于没有
